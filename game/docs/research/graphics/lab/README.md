# Lab scripts

Hands-on experiments from the graphics research (headless Blender via the `bpy` PyPI package, glTF-Transform, Playwright).
They are research artefacts, not production tooling; the skills in `.claude/skills/` hold the maintained versions.

`00_env.sh` is deliberately not included: it downloaded the KTX-Software binary from GitHub releases, which needs the
owner's approval under the repo's security rules. The default pipeline uses npm/PyPI packages only.
