# Assets

All art is procedurally generated in code (`src/render/`). No external models, textures, fonts or audio are used. The HD-2D prototype's pixel textures (`src/render/hd2d/textures.ts`), window cookie and figures are painted/built procedurally at runtime too; no CC0 or third-party packs.
