# Assets

All art is procedurally generated in code (`src/render/`). No external models, textures or audio are used. The only third-party files are the six UI fonts (Alegreya superfamily, SIL OFL 1.1) in `src/assets/fonts/`, listed below. `src/assets/fonts/orbkin-pixel.otf` is our own (generated from glyph bitmaps in `tools/pixelfont/glyphs.ts` by `tools/pixelfont/build.ts`); since the slab UI it is no longer loaded by any screen but stays in the repo with its tooling and tests. The HD-2D prototype's pixel textures (`src/render/hd2d/textures.ts`), window cookie and figures are painted/built procedurally at runtime too; no CC0 or third-party packs.
